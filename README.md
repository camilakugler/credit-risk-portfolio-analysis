# credit-risk-portfolio-analysis
Credit risk portfolio analysis using real Lending Club loan data, Python, PostgreSQL, SQL, and Power BI to investigate loan performance, credit losses, and risk indicators.

## Data Source

**Dataset:** Lending Club Loan Data (2007–2018)

**Source:** [Kaggle — All Lending Club Loan Data](https://www.kaggle.com/datasets/wordsforthewise/lending-club)

**Dataset published by:** Nathan George (Kaggle)

**Original data provider:** LendingClub

This project uses historical Lending Club loan data made publicly available through Kaggle.

The analysis focuses on accepted loan applications, examining loan characteristics, borrower financial profiles, credit risk classifications, and historical loan performance.

The dataset is used for educational and portfolio purposes as part of a credit risk analysis project.

**Note:** The original dataset is not included in this repository due to its size. It can be accessed through the source link above.
